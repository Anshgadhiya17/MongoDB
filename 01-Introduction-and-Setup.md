# 🍃 MongoDB – Introduction & Setup

## 📌 What is MongoDB?

MongoDB is a NoSQL database that stores data in JSON-like format called BSON.

It is:
- Document-based
- Flexible schema
- Highly scalable
- Fast

---

## 🆚 SQL vs NoSQL

| Feature | MongoDB | MySQL |
|----------|----------|--------|
| Type | NoSQL | SQL |
| Data Format | JSON (BSON) | Tables |
| Schema | Flexible | Fixed |
| Scaling | Horizontal | Vertical |

---

## 🚀 Features of MongoDB

✔ Schema-less  
✔ High performance  
✔ Replication  
✔ Sharding  
✔ Easy scaling  

---

# ⚙ Installation

## Local Installation

Download from official site and install.

Start server:

```bash
mongod
```

Open shell:

```bash
mongosh
```

---

## ☁ MongoDB Atlas (Cloud)

MongoDB Atlas is cloud database service.

Steps:
1. Create account
2. Create cluster
3. Get connection string
4. Connect using Compass or Node.js

---

## 🧭 MongoDB Compass

GUI tool for MongoDB.

Used for:
- View collections
- Insert data
- Run queries
- Analyze indexes
